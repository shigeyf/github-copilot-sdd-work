### 使用例

```typescript
import {
  createBulkNotes,
  cleanupNotes,
  simulateNetworkError,
  measureTime,
} from "../utils/testHelpers";

// テスト前のクリーンアップ
await cleanupNotes();

// 100 個のノートを作成
await createBulkNotes(100);

// ネットワークエラーをシミュレート
await simulateNetworkError(page, "**/notes", "GET");

// パフォーマンス計測
const time = await measureTime(async () => {
  await page.goto("/");
  await page.click("text=新規作成");
});
expect(time).toBeLessThan(3000);
```

## 次のステップ（ユーザー側で実施）

1. **依存関係のインストール**

   ```bash
   cd frontend
   npm install
   ```

2. **バックエンドと MongoDB の起動**

   ```bash
   # バックエンド
   cd backend
   source venv/bin/activate
   uvicorn src.main:app --reload

   # MongoDB
   docker run -d -p 27017:27017 mongo:latest
   ```

3. **テストの実行**

   ```bash
   # ユニットテスト
   npm run test

   # E2E テスト
   npm run test:e2e

   # カバレッジレポート
   npm run test:coverage
   ```

4. **リンターとフォーマッターの実行**

   ```bash
   npm run lint
   npm run format
   npm run type-check
   ```
